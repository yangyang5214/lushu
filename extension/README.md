# 路书助手（浏览器扩展）

在 `https://lushu.fittools.cc/d/…` 路书页面上，输入一个主题（路书名），插件会：

1. 自动打开小红书首页，在搜索框输入关键词，点出现的**「问点点」**入口，读取点点的回答；
2. 用**你自己的 DeepSeek Key**把原文里的地点全部提取出来，按顺路顺序排好；
3. 逐个调用路书的 `/api/places` 定位成坐标；
4. 调 `PUT /api/books/:id` **把地点写入当前打开的路书**（`/d/…` 里的 bookId）。

DeepSeek Key 只存在本机 `chrome.storage.local`，不会上传到路书服务端。

## 安装（开发者模式）

1. 打开 Chrome/Edge → `chrome://extensions`（Edge 是 `edge://extensions`）。
2. 右上角打开「开发者模式」。
3. 点「加载已解压的扩展程序」，选择本目录 `extension/`。
4. 点扩展图标 → 「全部设置」，填入 DeepSeek API Key，保存。

> 此扩展没有构建步骤，源码即产物，改完在扩展页点「重新加载」即可。

## 使用

1. 登录 `https://lushu.fittools.cc`，打开要生成的那本 `/d/xxx` 路书（或先新建一本）。
2. 点右下角圆形「路」按钮 → 输入路书名，例如「青甘大环线」。
3. 选生成方式：**小红书问点点** 或 **DeepSeek 生成**，再点「开始生成」。定位完成后会自动写入当前路书。

## 它是怎么“自动调小红书”的

小红书网页接口带签名，第三方很难直接调用。插件改用**真实页面**，固定一条流程：

- 打开小红书首页 `xiaohongshu.com/explore`，在页面主世界里写入搜索框并校验值真的进去了；
- 只点输入后新出现的「问点点」（不点导航栏常驻的「点点」）；写不进去就改走 `search_result?keyword=` 再点；
- 到了点点会话页，轮询读取回答，内容稳定后返回纯文本；若会话里没带上问题，会自动补发一次；
- 抓完自动关闭标签页，把文本交给 DeepSeek。

因此前提是**浏览器里已登录小红书**。若小红书 DOM 改版导致点不到／读不到，可在设置页的
「高级：页面选择器」里改「首页搜索框」「问点点入口」「回答容器」的选择器。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存配置 |
| `tabs` / `scripting` | 打开小红书标签页并注入抓取脚本 |
| `host_permissions: lushu` | 通过页面发起定位 / 写路书请求 |
| `host_permissions: xiaohongshu` | 抓取攻略内容 |
| `host_permissions: api.deepseek.com` | 调用 DeepSeek |

## 注意

- **写入需要登录**，且对当前这本路书有编辑权限（自己的书）。未登录时面板会提示先去登录。
- 写入是**覆盖当前路书的地点列表**，请在一本专用的路书里操作。
- 站点必须配置 `AMAP_KEY`，定位（高德 POI 检索）才能用；未配置时不会回落到其他地图源。
- 路书服务端没有开放 CORS，插件的写请求是借路书页面同源发出的（内容脚本），不会改动服务端安全模型。
