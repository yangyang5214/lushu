# 路书

先把整趟旅程铺成一条线，再在过夜的地方钉上分割针，把路剪成日子。

高德路书适合「按天添加目的地」。如果你已经想好整条线，只是还没决定在哪过夜，拆天会很别扭。这个工具反过来做：

1. **搜地点，可一直加。**
2. **定起点和终点。** 其余点按路程自动串起来。起终点是同一个地方，就当成环线，最后一天回到起点。
3. **在中间任意点设分割针。** 针钉在过夜地，一天就在这里切开。针可以在行程尺上拖到别的点，天数和地图颜色会跟着走。

打开先看到「我的路书」列表，每本路书都有独立的地址：`/<id>`（如 `http://localhost:5173/abbe26963b3f90f90b8ea659`），可直接收藏或分享；列表页在 `/`。

> 部署到静态服务器时，记得把未知路径回退到 `index.html`（SPA fallback），否则直接打开路书链接会 404。

## 本地运行

```bash
pnpm install
pnpm dev
```

打开提示的本地地址即可。列表页的「载入示例环线」是高德上那条 2026 中秋-国庆华东环线，方便直接试拆天。

数据存在浏览器本地，不会上传。
